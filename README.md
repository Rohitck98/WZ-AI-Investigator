# Work Zone Investigator - Starter

A SQL-free Streamlit and Pandas prototype.

## Run
1. Create and activate a virtual environment.
2. `pip install -r requirements.txt`
3. Put your CSV in `data/Sample 1.csv` or upload it in the app.
4. `streamlit run app.py`

## Supported starter questions
- How many work zones are there?
- Show northbound work zones
- Show work zones on IH 35
- Show active work zones on 2026-09-22
- Show full closures
- Find bridge work
- Which road has the most work zones?
